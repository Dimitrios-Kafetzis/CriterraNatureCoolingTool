\noindent\textbf{Openness statement.} \Tool{}, its complete methodology
configuration, its source code, and this document are public. The tool is
released under the Apache License, Version 2.0. Every quantitative value the
tool applies is derived in this document, recorded in machine-readable
configuration, and traced to a cited source whose verification status is
disclosed in \Cref{app:verification}. Readers are able to inspect, reproduce,
contest, and modify every element of the methodology described here.

\noindent\textbf{Corresponding methodology artefacts.} The normative
configuration files are \texttt{config/*.yaml}; the per-typology derivations
are \texttt{docs/methodology/EVIDENCE-TABLES.md}; the source register with
verification status is \texttt{docs/methodology/BIBLIOGRAPHY.md}. All carry the
version stamp \methver{} and move as a single unit.

\noindent\textbf{Invitation to review.} This document is written to be

envelopes (\Cref{sec:typologies}), the aggregation weights
(\Cref{sec:aggregation}), the derivation of energy savings
(\Cref{sec:energy}), and the treatment of uncertainty
(\Cref{sec:uncertainty}). \Cref{sec:governance} describes how to do so.
