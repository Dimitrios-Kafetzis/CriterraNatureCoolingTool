# v2.2 Brief — A Usable Map: Deployment Imagery, Place Search, and Leaflet

The brief for the release that makes the v2.1 map usable. Companion to
[DECISIONS.md](DECISIONS.md) — the design rulings are D-049, the
implementation rulings D-050 — and to [HOSTING.md](HOSTING.md), the operator
page this release owes.

**Status: implemented and shipped as package `2.2.0`, methodology unchanged at
`2026.08.05`.**

## Starting state, and the finding

v2.1 shipped map-based site selection with three-input autofill, ruled by
D-047/D-048: inline SVG over bundled Natural Earth outlines, no map library,
external tiles opt-in per user through a free-text field, and no runtime
configuration of any kind anywhere in the application. Reviewed in a browser,
the map was not usable enough to find a real site: land at `#dfe2d6` on
`#f3f4ec` is near-featureless at city zoom, nothing on the offline map is
findable by name, and per-user tile opt-in means nobody deploying the tool for
others can give their users imagery.

## The deployment model this release exists to serve

- Run locally on the author's machine: real imagery, one command.
- Deployed at criterra.eu for the company's users: real imagery, configured
  once by the operator.
- Hosted by UNEP or anyone else on their own premises: **they** configure
  imagery deliberately, and get the offline map until they do.
- A plain `pip install` phones out to **nobody** until an operator turns it
  on.

The rule therefore changes from *"the package never makes a third-party
request"* to *"the package makes no third-party request until a deployer
configures one, or a user opts in"* — the first runtime configuration this
application has ever had, recorded as an architectural decision with exactly
what is and is not conceded in **D-049.1**, superseding part of D-047.1.

## Scope, as ruled in D-049

1. **Deployment-level tile configuration** (D-049.2/.3/.4): two environment
   variables plus a CLI convenience flag; no config file; attribution required
   with the URL, refused at startup without it; browser-direct requests, never
   proxied; deployer imagery on by default with per-visit user off-switch and
   user-substitute source. `compose.yaml` carries a commented example;
   [HOSTING.md](HOSTING.md) documents providers, why `tile.openstreetmap.org`
   is not one, key restriction, and the unconfigured behaviour.
2. **The v2.1 attribution defect fixed structurally** (D-049.2): every tile
   source — deployed or user-named — carries its credit in the same
   configuration unit as its URL, and the map renders it whenever the layer is
   on. ODbL §4.3 is the reason; D-049.7 records the licence analysis.
3. **Offline navigation by name** (D-049.6): place search over all 7,342
   Natural Earth populated places (v5.1.2, public domain, 143 KB bundled).
   Selecting a place moves the map and fills in no answer.
4. **Leaflet adopted** (D-049.5), superseding D-048.5: BSD-2-Clause, zero
   dependencies, verified to instantiate fully under the jsdom test
   environment before the ruling. Ships in the wheel with its licence text and
   NOTICE entry; the licence gate extends over it.
5. **Contrast raised within the design tokens**: land is an accent tint over
   raised paper with ink edges, sea is base paper — separated by hue and value
   at once.
6. **Stale copy fixed**: the entry screen and README now describe the
   seven-step wizard (optional map + six question steps) the interface
   actually shows.

## Out of scope, restated

Autofill remains exactly the three D-047 inputs (`site_area_m2`, `country`,
`climate_zone`). Deriving canopy, imperviousness, LST or land use from imagery
remains the GIS workflow deferred by D-002 and refused by D-047 — real imagery
on screen makes this temptation stronger, not weaker, and neither place search
nor the tile layer is a back door to it.

## Gates

All existing gates unchanged — 100% backend coverage, D-017 evidence gates,
golden scenarios, ruff + format, mypy --strict, eslint, prettier, tsc, the
OpenAPI/schema.ts drift gate, strict docs build, wheel smoke check — plus:

- the **bundled-content licence gate extended** over the place index and the
  redistributed map library; and
- the **request gate replaced by something stronger** (D-049.8): the static
  six-shape check stays, and a runtime check drives the built app headlessly —
  unconfigured through a complete assessment asserting zero external requests,
  then configured against a local mock host asserting requests go only there
  and the credit renders, then against an unreachable host asserting the map
  degrades to the bundled outlines and the assessment stays completable.

**No methodology version bump.** The place-search index changes no scoring
value and enters no formula; it is a bundled dataset under the licence gate,
not a methodology value (D-049.6). The sensitivity analysis is re-confirmed
byte-identical, the D-048.7 treatment.
